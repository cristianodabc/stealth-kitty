# Changelog

## 0.4.0 - 2026-09-29

- Choose Lumo's built-in web, weather, stock, cryptocurrency, and Proton
  information tools in the terminal chat with Ctrl+L.
- Keep tool choices with each conversation and carry them into new chats.
- Preserve the Ctrl+W web shortcut and show its state independently of other
  selected tools.

## 0.3.0 - 2026-09-29

- Choose Classic, Ocean, or Amber terminal themes at launch or from the chat.
- Keep model, mode, web, file, and theme controls visible in a tighter layout,
  including on narrow terminals.
- Show an ASCII cat on the empty conversation screen.

## 0.2.1 - 2026-09-29

- Highlight fenced code in more than 200 languages, including Python, Ruby,
  Rust, Go, JavaScript, TypeScript, Bash, SQL, and YAML.
- Recognize common file extension labels such as `sh` and `py`.

## 0.2.0 - 2026-09-29

- Render Markdown replies with highlighted Elixir, Erlang, and JSON code.
- Keep multiple in-memory terminal conversations with a hideable sidebar.
- Improve narrow layouts, long-prompt editing, and conversation navigation.
- Show scroll position, mark incomplete replies, and add a shortcut guide.
- Refresh the spark branding and space the model, mode, web, and file controls.

## 0.1.0 - 2026-09-29

- Add an encrypted Elixir client for Proton Lumo with guest access.
- Add a Terra terminal chat and one-shot command-line prompts.
- Support Apertus 1.5, Lumo 2.0 Lite and Max, Fast and Thinking modes,
  web search, and local file attachments.
- Add native OpenPGP request-key wrapping, documentation, tests, and CI.
